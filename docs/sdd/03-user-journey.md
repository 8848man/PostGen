# User Journey

## 처음 사용하는 사람

1. 사용자가 현재 작업 폴더에서 콘텐츠 제작 Skill을 호출한다.
2. Skill은 해당 폴더에 연결된 Codex·Claude Code 기록과 Git 후보의 짧은 목록을 자동 탐색한 뒤 관련 본문만 읽는다. 기본 흐름에서 입력 파일·프리셋·주제를 선택시키지 않는다.
3. 관련 정보가 충분하면 주제와 독자 가치를 판단하고 Knowledge Package를 만든다.
4. 기본 프로필로 블로그 초안을 CLI 대화에 제시한다. 불확실한 사실과 근거를 확인할 수 있게 표시한다.
5. 사용자가 대화로 수정한다. 수정 결과는 이번 글에만 적용하고, 명시적 지속 요청 또는 동일 스타일 속성의 반복 수정일 때만 저장을 제안한다.
6. 사용자가 내보내기를 요청하면 형식과 경로를 확인해 파일을 만든다.

## 고급 설정을 사용하는 사람

1. 사용자가 HTML 설정 화면을 연다. 기본 콘텐츠 제작에 앞서 강제하지 않는다.
2. 목적 해시태그가 있는 3개 프리셋을 비교하거나 속성을 직접 지정한다.
3. 이미지·HTML·텍스트 레퍼런스를 추가하면 분석된 추론 속성을 먼저 보여준다. 명시적으로 지정한 값과 구별한다.
4. 설정 채팅에서 자연어로 변경을 요청하면 AI가 스키마에 맞는 명령을 제안한다. 검증된 명령이 Profile에 반영되고 화면에 결과가 갱신된다.
5. `생성 전에 주제 선택하기`를 켜면 다음 생성 요청에서 주제 후보를 본다.

## 빈 상태와 오류

- 현재 폴더에 연결된 기록이 없거나 유의미한 자료가 부족하면 무리한 글을 생성하지 않는다. 원인을 설명하고 현재 폴더 확인, 다른 폴더에서 Skill 실행, 사용자가 명시적으로 제공한 자료 추가를 안내한다.
- 읽기 실패·잠금·파싱 실패는 가능한 기록으로 계속 진행할지 판단하고 누락 범위를 알린다. 근거가 부족해 사실을 확정할 수 없으면 초안에 불확실성을 표시한다.
- 민감 정보로 의심되는 내용은 사용자에게 표시·제외 기회를 제공한다. 다른 폴더를 자동 탐색하지 않는다.
