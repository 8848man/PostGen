# Implementation Roadmap

MVP 구현·설치·기술 시험은 2026-10-20에 승인받아 진행했다. 아래 단계의 코드 경로는 [Skill](../../skill/postgen/SKILL.md)에 있다. 파일럿 품질 평가는 남아 있다.

## 0. 기술 성립성 검증

의존성 설치나 본격 구현 전에 Codex Skill 발견·호출, 작업 폴더별 기록 추적, 설정 HTML 채팅의 지원 통합 경로를 확인한다. 각 결과를 `verified`, `failed`, `needs_validation`으로 기록한다. 설정 채팅 경로가 성립하지 않으면 ADR-007과 MVP 일정을 재검토한다.

## 1. 계약과 합성 자료

SourceDocument, Knowledge Package, Style Profile, SettingCommand, ContentPlan, BlogDraft의 JSON 스키마를 구체화한다. 합성 Codex 기록과 근거·충돌·빈 상태 사례를 만든다. 계약·안전성 테스트가 통과해야 다음 단계로 간다.

## 2. Skill 핵심 경로

프로젝트 범위 기록 탐색, 근거 추출, 주제 자동 선정, ELI5 블로그 초안, CLI 수정 흐름을 연결한다. 선택 단계 없이 첫 초안이 나오는지, 근거 없는 주장이 차단되는지 확인한다.

## 3. 프로필과 HTML 설정

기본 프로필·3개 프리셋·레퍼런스 분석·설정 명령 검증을 구현한다. 로컬 HTML 화면과 Codex 설정 채팅을 연결한다. 이 단계는 MVP 필수이며 설정 채팅까지 수용 기준을 충족해야 한다.

## 4. 렌더링과 내보내기

CLI 미리보기, 수정 상태, Markdown/HTML 내보내기, 안전한 경로·덮어쓰기·HTML 정화를 확인한다. 기본 요청에서는 파일을 만들지 않는지 검사한다.

## 5. 파일럿과 출시 판단

다양한 작업 기록으로 게시 가능성, 수정량, 사실 오류, 첫 초안 시간을 측정한다. 수용 기준과 결함을 검토해 MVP 완료 여부를 결정한다. 측정 결과에 따라 프리셋·ELI5·주제 선정 정책을 조정한다.

## 2026-10-24 입력 일반화 보강

Codex 실행 호스트를 유지하며 Codex·Claude Code 로컬 기록, 명시 로그 파일, Git 보조 근거를 공통 SourceDocument로 정규화했다. 후보 목록과 선택 읽기를 분리해 기본 36,000자 읽기 한도를 적용했다. 실제 혼합 도구 기록으로 게시 가능성·관련성 평가와 버전별 Claude Code 호환성 검증은 남아 있다.

## 후속 단계

제품 필수 목표인 다중 실행 호스트를 Codex MVP와 별도 단계로 추진한다(ADR-011).

1. Claude Code: Skill 설치·호출, 동일한 Knowledge·Style 계약을 이용한 생성·수정·내보내기, 설정 경로를 실제 환경에서 검증한다.
2. Claude Cowork: Skills 호출 방식, 실행 위치, 로컬 파일·기록 접근을 기술 검증한 뒤 가능한 입력 브리지와 설정 경로를 설계·검증한다. Claude Code Adapter를 그대로 재사용한다고 가정하지 않는다.
3. 다른 호환 AI: Host Adapter 기능 계약과 수용 시험을 통과한 호스트를 순차 지원한다. 기록 제공자는 실행 호스트와 별도로 추가한다.

산출물·근거 문서 백로그 시스템도 후속 Todo다. 영상 대본·스토리보드, 자동 이미지·영상 렌더링, 대규모 레퍼런스 관리는 별도 확장으로 평가한다. 각 후속 단계의 일정과 구현은 아직 승인되지 않았다.

브라우저 등록은 별도 후속 마일스톤으로 추가한다(ADR-012). 먼저 채널별 콘텐츠 변형과 근거 보존을 검증하고, 브라우저 편집기 입력·검수·채널별 승인·결과 확인을 X·Threads·네이버 블로그·티스토리 각각에서 순차 시험한다. 일정과 다른 후속 과제와의 우선순위는 아직 결정하지 않았다. [Publication Flow Contract](15-publication-flow.md)에 시험 게이트를 둔다.

## 운영·평가 잔여 작업

대화 밀도와 주제가 다른 실제 사용자 사례로 게시 가능성·수정량·사실 오류를 측정한다. Codex 버전 변경 시 기록 제공자와 Skill 호출 회귀 검증을 수행한다.
