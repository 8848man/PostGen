## 검증 결과와 한계

- Codex CLI는 `--json`, `--output-schema`, `--ephemeral`, `--sandbox` 옵션을 노출한다.
- 제한된 조사 샌드박스에서 첫 `codex exec` 응답 시험은 상태 DB 접근 `os error 5`로 실패했다. 이후 승인된 실행 환경에서 같은 읽기 전용·임시 실행 시험은 성공했다. 상태 DB 경고는 제품 자체의 인증 실패가 아니었다.
- 현재 폴더와 연관된 기록이 1건뿐이므로 자동 탐색은 가능한지 확인했지만, 의미 있는 다중 기록에서의 주제 추출은 검증되지 않았다.
- JSONL의 `session_meta.cwd`는 관찰한 구현 세부사항이다. 향후 버전에서 불변인 공개 계약으로 간주하지 않는다. 읽기 제공자를 격리하고 버전 변화·파일 잠금·손상 데이터를 검증한다.
- 공식 문서는 Skill이 `SKILL.md`와 선택적 보조 리소스로 구성됨을 설명한다: [OpenAI Docs: Skills](https://developers.openai.com/api/docs/guides/tools-skills). Codex의 JSONL 구조화 출력 및 앱 서버 프로토콜은 각각 [공식 평가 가이드](https://developers.openai.com/blog/eval-skills), [앱 서버 문서](https://developers.openai.com/siwc/token-sharing-open-source/codex-app-server)에 제시된다. 이 문서가 로컬 환경의 동작 성공을 보증하지는 않는다.
