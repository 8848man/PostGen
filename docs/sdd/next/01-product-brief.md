# Product Brief — PostGen Next

## 목표

PostGen은 사용자가 **직접 선택한** AI 작업 기록, 텍스트·파일, 공개 URL, 연결 서비스 문서를 근거로 여러 게시 계정의 글을 만든다. 글의 품질과 승인한 골든 샘플의 일반적 표현 규칙 재현이 첫 번째 목표다. 계정별로 글을 작성하고 이미지를 제안·생성한다. 사용자가 최종본과 공개 시각을 승인하면 PostGen이 해당 플랫폼에 예약 발행을 등록하고 플랫폼이 지정 시각에 공개한다. 예약 등록과 공개 결과를 각각 확인한다.

첫 대상 채널은 네이버 블로그·티스토리다. 이후 X·Threads와 사용자가 등록한 MCP 연결 커뮤니티를 지원한다. 콘텐츠 생성 호스트(Codex·Claude Code), 모델 제공자, 입력 제공자, 게시 채널은 별개 확장 축이다.

## 품질 원칙

1. 같은 자료라도 계정별 독자·목표·골든 샘플에 맞춰 독립 작성한다. 공통 기획은 핵심 주장과 근거까지다.
2. 계정별 대표 골든 샘플 하나를 기본으로 한다. 파일·텍스트·게시 URL·화면 캡처를 받을 수 있고, 추출한 문체·구성·문단·이미지 규칙은 사용자가 수정·승인한다. 규칙은 필수와 선호로 나눈다.
3. 공개된 타인의 샘플에서는 일반적 특징만 배운다. 고유한 문장·구도·캐릭터를 복제하지 않는다. 외형을 유지할 캐릭터·오브젝트 자산은 사용자가 만들었거나 사용 권한이 있는 자료만 등록한다.
4. 독자는 글마다 지정하고 목표는 계정 기본값을 사용하거나 덮어쓴다. 독자·목표와 샘플 선호 규칙이 충돌하면 독자·목표가 우선한다. 필수 규칙과 충돌하면 사용자에게 판단을 요청한다.
5. 한 편의 초안을 제시하고 피드백으로 다듬는다. 근거·규칙·샘플 재현도를 자동 점검해 이유와 함께 보여주되 최종 품질 평가는 사용자가 한다.
6. 출처가 충돌하면 초안은 만들되 주장에 검토 표시를 남긴다. 미해결 항목이 있어도 사용자가 명시적으로 확인하면 계정별 승인과 예약을 허용한다.

## 성공 기준

핵심 지표는 사용자가 평가하는 **승인된 골든 샘플 규칙의 재현도**다. 자동 평가와 사용자 평가를 함께 기록한다. 초기에는 실제 사용 글의 평가를 기준선으로 모으고, 버전별 추세를 본다. 수치 목표는 기준선 이후 결정한다. 근거 오류, 큰 수정 횟수, 이미지 일관성, 편집기 준비 성공률은 보조 지표다.

## 현행과 목표의 경계

현행은 Codex CLI Skill이 AI 작업 기록으로 블로그 초안을 만들고, 요청 시 Markdown/HTML을 내보낸다. 위 목표는 리팩토링 요구사항이다. 첫 구현 단위와 미구현 항목은 [Delivery Scope](02-delivery-scope.md)에 표시한다.
