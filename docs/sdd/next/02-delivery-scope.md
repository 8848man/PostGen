# Delivery Scope

## 단계

| 단계 | 완료 조건 |
| --- | --- |
| A. 품질 기반 | 계정별 대표 샘플·승인 규칙·이미지 자산 메타데이터, 선택 입력 묶음, 공통 근거 기획, 계정별 초안, 규칙별 평가를 저장·검증한다. Codex·Claude Code에서 같은 계약을 사용한다. |
| B. 제작 화면 | 로컬 화면과 Skill 양쪽에서 자료 선택·생성·수정·승인을 수행한다. 화면의 생성 버튼은 선택한 호스트를 호출하며 기본 진행 상태는 화면에 표시한다. 공통 모델 직접 호출을 선택할 수 있다. |
| C. 플랫폼 예약 발행 | 계정별 최종본과 공개 시각 승인, 글·이미지 입력 및 위치 검증, 플랫폼 예약 등록 확인, 지정 시각 이후 공개 URL 확인을 구현한다. 예약 등록 전 대기·실패 건의 알림과 재승인도 포함한다. |
| D. 채널 확장 | X·Threads를 검증하고 사용자가 등록한 MCP 연결 커뮤니티를 같은 채널 계약으로 추가한다. 독립 UI 생성과 서버 상시 실행은 후속 단계다. |

첫 출시 목표에는 A~C와 네이버·티스토리의 복수 계정이 포함된다. **구현 순서는 A→B→C**이며 실계정 게시 시험과 채널별 편집기 검증 없이는 C를 완료로 표시하지 않는다. 이 순서는 첫 사용 가능한 버전의 범위를 확정한 답변이 없었던 지점을 실행 가능한 단계로 나눈 결정이다.

## 명시적 후속/제외

### 초안 동시 편집 계약 (N-006)

화면에서 초안 수정을 시작하면 작업 ID별 편집 잠금을 얻고, 저장·취소 시 해제한다. 잠금이 유효한 동안 Skill CLI를 포함한 다른 작성자는 그 초안을 변경할 수 없으며 읽기는 허용한다. 잠금은 30분 뒤 만료되고, 저장 시 잠금 토큰과 최신 revision을 다시 확인한다. 만료되거나 다른 작성자가 변경한 초안은 덮어쓰지 않고 새로고침을 요구한다. 모든 작업 저장은 별도의 짧은 파일 잠금 안에서 최신 revision을 확인해 직렬화한다. 구현 세부 계약은 [Data Contracts](04-contracts.md)를 따른다.

- 로컬 화면 단독의 생성은 후속 단계다. 초기 화면은 AI 호스트 호출을 통해 생성한다.
- 클라우드 상시 예약과 기기 간 동기화, 팀 공유는 첫 출시 밖이다. 기본 데이터는 이 컴퓨터에 저장한다.
- 승인된 예약 발행은 첫 출시 범위다. 즉시 공개로 대체하지 않고, 플랫폼이 예약 기능을 제공하지 않으면 실패 상태를 보여준다.
- 새 채널에 골든 샘플이 없어도 기본 스타일로 시작한다.

## 구현 전 확인할 미결정 사항

- 네이버·티스토리의 PostGen 전용 Edge 프로필 로그인과 전체 자동 입력, 예약 등록 영수증과 공개 URL의 실제 신호.
- Codex·Claude Code의 화면 호출 및 백그라운드 실행 경로와 모델/이미지 기능.
- OpenAI·Anthropic 직접 호출의 구체적 모델, 비용 추정 입력, 인증 정보 저장 방식.
- 사용자가 지정하는 MCP 서버의 도구·권한 정보, 초안 입력 여부, 실제 계정에 대한 연결 검증.
- 보관 기한의 실제 삭제 작업 주기와 사용자가 복원할 수 있는 범위.
