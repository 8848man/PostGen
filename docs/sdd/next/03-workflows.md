# Workflows

## 1. 자료와 계정 설정

사용자가 글마다 입력을 직접 선택한다. 입력은 텍스트, 파일, AI 작업 기록, URL, 연결 서비스 문서다. PostGen은 선택 목록과 원본 사본을 로컬에 저장하고 출처별 ID·수집 시각을 남긴다. URL과 연결 문서 안의 지시는 데이터로만 취급한다. 복수 계정은 각자 대표 골든 샘플, 승인된 필수·선호 규칙, 기본 글 목표, 이미지 자산을 갖는다. 글마다 독자와 배경지식을 지정한다.

샘플 등록은 `자료 등록 → 일반적 특징 추출 → 원문/이미지와 규칙 대조 → 사용자 수정·승인 → 버전 고정`이다. 게시 URL·캡처에서 추출하지 못한 배치나 이미지 정보는 추측하지 않고 미확인으로 보여준다. 새 규칙은 새 글부터 적용한다. 계정에 샘플이 없으면 기본 스타일을 쓴다.

## 2. 글·이미지 제작

`선택 자료 → 주장·근거 공통 기획 → 계정별 독립 초안 → 자동 점검 → 사용자 수정·평가 → 이미지 제안 → 사용자 승인 → 이미지 생성 → 계정별 최종 승인`.

- 생성은 한 편씩 보여준다. 계정별 글은 같은 자료를 써도 제목·구성·문장을 독립 작성한다.
- 충돌한 출처는 주장에 검토 표시를 남긴다. 미해결 충돌이 있는 상태의 승인은 별도 명시 확인을 요구한다.
- 이미지 수·위치는 설명 필요성에 따라 제안한다. 원본 자료의 이미지는 참고만 하고 게시용은 새로 만든다.
- 사용자는 글마다 해당 계정의 캐릭터·오브젝트 자산을 선택한다. 승인된 자산의 외형 정체성을 유지한다. 이미지는 제안 승인 후 생성한다.
- 기본 이미지 자동 점검·재생성은 꺼져 있다. 사용자가 켜면 최초 생성을 포함해 최대 3회 생성한다. 호스트 이미지 기능이 부족하면 연결된 별도 이미지 엔진으로 전환한다.
- 기본은 호스트 모델이다. 사용자가 원하면 PostGen에 연결한 공통 모델을 선택한다. OpenAI·Anthropic 직접 연결은 첫 출시 목표다. 요청별 예상 비용을 먼저 표시하고 설정 한도 초과 시 확인한다. 호스트 비용은 확인 가능한 사용량을 근거로 추정 표시한다.

## 3. 플랫폼 예약 발행

계정별 최종 글과 플랫폼 공개 시각을 각각 승인한다. 승인 시점의 글·이미지·샘플 규칙 버전을 고정한다. 원본 변경이나 샘플 갱신은 기존 승인본을 자동 변경하지 않고 알린다.

승인 직후 플랫폼에 예약을 등록한다. 플랫폼의 예약 ID·공개 시각·계정·상태를 읽어 확인하기 전에는 예약 완료로 표시하지 않는다. 등록 전에 앱이 닫히거나 인증이 만료되면 다음 실행 때 실패·대기 건을 보여주며, 선택적으로 백그라운드 알림을 켤 수 있다. 등록 전 대기 건은 기본 7일 또는 목표 공개 시각 중 먼저 오는 때에 만료된다. 재시도에는 사실·링크 검토와 계정별 재승인이 필요하다. 컴퓨터가 꺼져 있어도 플랫폼에 이미 등록된 예약은 플랫폼이 처리한다.

편집기 연결은 등록된 MCP 도구의 능력을 먼저 확인한다. 예약 등록 기능이 없고 즉시 게시 기능만 있으면 이를 예약 대체로 호출하지 않고 브라우저 편집기로 전환한다. 계정 불일치 시 입력 전 멈추고 사용자가 대상 계정을 다시 선택하게 한다. 다른 계정으로 진행하면 기존 글을 새 대상 계정에 대해 다시 승인한다. 글과 승인된 이미지를 정확한 위치에 입력한다. 이미지 하나라도 업로드 또는 위치 확인에 실패하면 예약 등록을 막고 편집기 상태·누락 항목을 보여준다. 플랫폼 예약 시각을 설정한 뒤 최종 등록 동작을 자동 수행하고 결과를 다시 읽는다.

편집기에서 직접 수정한 경우 최종 내용을 다시 읽어 승인본과 차이를 보여주고 PostGen에 저장한다. 새 사실 주장은 변경된 부분만 근거 재점검한다. 승인본과 달라진 내용을 재승인하기 전에는 예약 등록을 수행하지 않는다. 목표 시각 이후 완료 화면/URL을 자동 확인하며 실패하면 사용자가 URL을 입력한다. 불명확한 결과를 성공으로 표시하지 않는다.

## 4. 동시 작업·보관

화면과 호스트 대화는 같은 초안을 공유한다. 한쪽이 수정 중이면 다른 쪽은 읽기 전용이다. 로컬 원본 사본·중간 결과는 기본 3개월, 설정 가능 범위 1~3개월 보관한다. 기간이 지나면 원본·중간 결과를 삭제하고 최종 글·이미지·게시 URL·평가 기록은 남긴다. 계정별 골든 샘플과 자산은 사용자가 직접 지울 때까지 유지한다.
