# MVP Scope와 후속 Todo

> 아래 범위는 기존 MVP의 기록이다. 리팩토링의 단계별 범위는 [Next Delivery Scope](next/02-delivery-scope.md)를 따른다.

## MVP 필수

| 영역 | 범위 |
| --- | --- |
| 호출 | Codex CLI에서 명시적으로 호출 가능한 Skill, 기본 설정 없이 실행 |
| 소스 | 현재 작업 폴더와 연결된 Codex·Claude Code 기록 자동 탐색, 명시적 텍스트 로그 입력, Git 커밋 보조 근거, 읽기 오류·기록 부족 처리 |
| 지식 | Fact, Decision, Evidence, Insight, Example, Asset을 담는 JSON Knowledge Package; 원본/파생·출처 구분 |
| 기획·생성 | 주제 자동 선정, 설명 대상과 핵심 메시지 계획, ELI5 블로그 초안, 근거 확인 |
| 수정 | CLI 대화에서 내용·구조·스타일·사실 오류를 구별해 수정. 지속 스타일 제안은 반복/명시 요청 때만 |
| 설정 | 기본 프로필, 목적 해시태그가 붙은 서로 다른 3개 프리셋, 필수 로컬 HTML 설정 화면, 검증 가능한 설정 명령, 이미지·HTML·텍스트 레퍼런스 입력과 추론/직접 지정 속성 구분 |
| 출력 | CLI 초안 미리보기, 요청 시 Markdown/HTML 내보내기 |
| 추적 | 초안의 사실 주장과 근거 위치 연결. 별도 지속 백로그 시스템은 제외 |
| 보호 | 현재 폴더 범위 강제, 민감 정보 비노출, 입력 내용을 명령으로 실행하지 않음 |

## MVP에서 제외

- Claude Code·Claude Cowork 등 다른 AI를 글 생성 호스트로 실행하는 기능. Claude Code 로컬 기록 입력은 지원하되 호스트 실행은 현재 Codex에 남긴다. 이는 제품 범위 제외가 아니라 MVP 이후 필수 확장이다.
- 이미지 자동 생성과 영상 대본·스토리보드·영상 렌더링
- 그래프 DB, 복잡한 온톨로지, 레퍼런스 라이브러리와 자동 동기화
- 게시 플랫폼 직접 발행, 계정 연동, 협업 기능. X·Threads·네이버 블로그·티스토리의 브라우저 등록 흐름은 후속 마일스톤(ADR-012)이다.
- 생성 산출물과 근거 문서를 장기 보관·추적·재검토하는 백로그 시스템

## 후속 Todo

1. **산출물·근거 백로그:** 생성한 콘텐츠와 근거 문서를 연결해 보관한다. 버전, 상태, 출처 변경, 재검토 필요 여부를 추적한다. Knowledge Package의 안정적 식별자와 출처 참조를 확장 지점으로 남긴다.
2. **호스트 독립 실행:** Claude Code에서 Skill 설치·호출·글 생성·수정·내보내기 검증, 이어 Claude Cowork의 실행 환경과 로컬 파일 접근 방식에 맞는 Adapter/입력 경로 검증. 호환 가능한 다른 AI 호스트용 계약과 적합성 시험을 유지한다. 이는 제품 목표의 필수 단계이며 일정만 별도로 결정한다.
3. Claude Code 이외 제공자의 기록 입력, 저장되지 않은 터미널 출력 캡처, 대화 주제 인덱스·요약 캐시는 별도 평가한다.
4. 매체별 Content Skill 추가: 영상 대본, 스토리보드, 영상.
5. 이미지 자동 생성·시각 자료 제안 정책과 자산 관리.
6. 대규모 레퍼런스 검색/관리. 실제 규모와 탐색 요구가 확인될 때 저장 기술을 재평가한다.
7. **브라우저 등록:** X·Threads·네이버 블로그·티스토리용 채널 변형, 브라우저 편집기 입력, 채널별 확인·발행·결과 추적. [Publication Flow Contract](15-publication-flow.md)에 세부 흐름을 둔다. 현재 구현·실계정 시험은 포함하지 않는다.

## 범위 판단 기준

기능이 첫 초안의 품질, 수정량, 안전한 기록 탐색에 직접 기여하면 MVP 후보로 삼는다. 비용이 크고 핵심 가설에 대한 직접 기여가 낮으면 후속으로 둔다. HTML 설정 화면은 사용자가 MVP 필수로 확정한 예외가 아니라 제품 요구사항이다.
