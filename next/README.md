# PostGen Next 실행·검증 상태

`npm install` 후 `npm run next`로 로컬 화면을 연다. 서버는 `127.0.0.1`에만 바인딩하고 실행 시 출력된 토큰 URL을 사용한다. 로컬 데이터는 기본적으로 사용자 PostGen 데이터 디렉터리의 `next/`와 계정 레지스트리에 저장한다. 시험용 데이터는 `POSTGEN_DATA_DIR`과 `POSTGEN_NEXT_DIR`로 분리할 수 있다.

## 현재 사용할 수 있는 흐름

- 계정·골든 샘플·이미지 자산 등록. 샘플 텍스트/파일/URL/캡처 분석은 Codex CLI를 호출하고, 규칙은 사용자 승인 전에는 기본값으로 쓰지 않는다.
- 직접 텍스트·파일·공개 HTTPS URL·선택한 Codex/Claude 기록·승인된 MCP 문서 도구를 입력 스냅샷으로 만든다.
- Codex·Claude CLI 또는 환경 변수에 키가 설정된 OpenAI·Anthropic API로 초안을 요청한다. 자동 규칙 평가는 별도 모델 호출이며 실패 시 경고를 기록한다.
- 이미지 제안을 승인하고 계정 자산을 선택한 뒤 OpenAI Image API로 생성한다. 자동 점검은 기본 꺼짐이며 설정에서 켜면 최대 3회 생성·점검한다. 실패한 점검 결과는 사용자가 검토해야 한다. 호스트 이미지 기능 자동 호출은 아직 연결하지 않았다.
- 계정별 승인, 예약, 7일 만료, 재승인, 로컬 화면에서의 기한 확인. 설정에서 Windows 알림을 켜도 서버를 계속 실행해야 한다. 원본·중간 자료 보관은 1~3개월로 설정한다. 만료 자료는 실행 시·하루 1회 활성 작업에서 제거하며, 14일 동안 복원할 수 있다.
- 설치된 Skill의 `scripts/next-cli.mjs`와 로컬 화면은 같은 작업 저장소를 읽는다. Skill에서 계정별 초안을 만들거나 수정·승인할 수 있다. 화면의 초안 수정 중에는 같은 초안의 CLI 쓰기를 잠그며, 잠금 만료나 revision 충돌 시 새로고침 후 다시 수정한다.
- 계정별 최종본과 공개 시각을 승인하면 플랫폼 예약 등록을 시도한다. 브라우저 경로는 PostGen 전용 Edge 프로필을 사용하므로 그 창에서 직접 로그인해야 한다. 네이버·티스토리 글/예약 필드 코드를 추가했지만 실제 예약 완료는 검증하지 않았다. 등록 결과가 불명확하면 `unknown`으로 두고 자동 재시도하지 않는다.

## 비용·인증

직접 API 호출은 `OPENAI_API_KEY` 또는 `ANTHROPIC_API_KEY` 환경 변수를 사용한다. 모델 이름은 생성 화면에서 지정한다. `POSTGEN_PRICE_TABLE`은 가격표 JSON 파일 경로이며 키는 `provider:model`, 값은 `inputPerMillion`, `outputPerMillion`이다. `POSTGEN_COST_LIMIT_USD`로 요청별 한도를 지정할 수 있다. 이미지 가격표 키는 `image:openai:<model>:generation` 또는 `image:openai:<model>:edit`이며, 값에 확인한 이미지 1회 가격 `perImageUsd`, `verified: true`, 가격 출처 `sourceUrl`, 확인일 `verifiedAt`(YYYY-MM-DD)을 기록한다. 해당 항목이 없으면 이미지 비용은 추정 불가로 표시한다. 자동 이미지 점검 비용은 별도이며 총액에 포함되지 않는다. 가격표가 없으면 금액을 추정하지 않고 실행 전 확인한다. API 키를 PostGen JSON 파일에 저장하지 않는다.

## 미완료 검증

2026-11-06 기준 Codex CLI 구조화 응답은 실호출 통과. Claude CLI는 상태 명령상 로그인으로 표시되지만 실호출 시 OAuth 세션 만료로 실패했다. OpenAI·Anthropic 직접 API 키가 없어 실호출은 미검증이다. Edge의 합성 편집기에서는 계정 확인·필드 입력·문단별 이미지 위치·읽기 확인을 통과했다. 로그인된 네이버·티스토리 화면에서 테스트 이미지가 첫 문단과 둘째 문단 사이에 업로드된 것을 확인하고 편집기 테스트 내용을 지웠다. 예약 설정 화면도 확인했으나 최종 등록은 하지 않았다. **PostGen 전용 Edge 프로필에서의 전체 입력, 플랫폼 예약 등록 완료, 공개 URL 확인은 미검증**이다. 해당 화면에서 검증하기 전에는 A~C 완료로 표시하지 않는다.

네이버·티스토리 기본 글·예약 필드는 관찰된 화면에 맞춰 연결했다. 두 서비스의 이미지 업로드·문단별 위치를 로그인된 실제 편집기와 합성 편집기에서 확인했다. 실제 로그인된 화면은 컴퓨터 제어로 검증했고 PostGen의 독립 Edge 프로필을 통한 전체 자동 경로는 아직 검증하지 않았다. 일반 편집기 선택자 JSON 경로는 별도 실험용으로 남겨두었다. 네이버는 [스마트에디터 ONE에서 HTML 작성 기능을 지원하지 않는다](https://help.naver.com/service/5593/contents/15545?lang=ko&osType=PC). 티스토리는 [에디터 모드 전환 시 서식 변화가 있을 수 있다](https://notice.tistory.com/2482).
